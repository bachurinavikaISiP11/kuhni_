# FORM Kitchen Studio

Статический многостраничный сайт для компании по изготовлению кухонь на заказ.

## Структура
- index.html — главная
- catalog.html — каталог с фильтрами
- services.html — услуги + калькулятор
- portfolio.html — портфолио
- contacts.html — контакты и форма
- assets/style.css — стили
- assets/script.js — интерактив
- assets/*.svg — локальные визуалы

## Запуск
Просто откройте `index.html` в браузере. Сервер и сборка не нужны.

## Настройка
Замените:
- название FORM и контакты в HTML;
- адрес, телефон и email;
- SVG-изображения в папке assets на реальные фотографии;
- цвета и типографику в `assets/style.css`.

Формы сейчас демонстрационные: после отправки показывается сообщение без отправки на сервер.
